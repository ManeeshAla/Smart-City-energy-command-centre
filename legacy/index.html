Smart Grid Investment Insight
The batch analysis groups cities by how much they've adopted smart grids. This tells planners: "do cities with more smart grid tech actually use energy differently?" — backed by data from thousands of cities.
⚙️
No Retraining on Every Restart
The trained ML model is saved to disk using Joblib. When the server restarts, it loads the saved model in milliseconds instead of retraining — crucial for production deployments that restart frequently.
🗄️
Industry-Standard Storage Formats
Parquet (used by Apache Spark, BigQuery, AWS Athena) stores the full dataset for batch analysis. JSONL stores every event, prediction and alert in a format ready for Kafka or Elasticsearch pipelines.

Model Evaluation
How accurate is the machine learning model?
LINEAR REGRESSION
Trained on: 4,000 cities  |  Tested on: 1,000 unseen cities.
The model uses 13 city features: population, area, transport, air quality, education, healthcare, employment, smart grid, waste, internet speed, safety, infrastructure score, and cost of living.
Parquet Batch Storage
All 5,000 cities saved in a fast, compressed format used by Apache Spark and Google BigQuery
PARQUET
Why Parquet? 10–100× smaller than CSV, and reads 10× faster for analytics queries. The same file can be queried directly by Spark, Pandas, or BigQuery without any conversion.
Joblib Model Persistence
Trained model saved to disk — reloaded instantly on restart
JOBLIB
Why Joblib? Serialises the entire scikit-learn pipeline (scaler + model) in one file. Loading takes milliseconds vs. several seconds of retraining — essential for APIs that restart under traffic.
